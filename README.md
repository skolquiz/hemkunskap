# Konsumentekonomi – träna inför provet

Interaktiv träningssida i hem- och konsumentkunskap (åk 9): sex områden med fakta, provfrågor med svar och begreppskort.

- `index.html` – hela sidan (HTML, CSS och JS i en fil)
- `img/` – scenbilder (FigureLabs)
- `page.html` + `build.py` – källa för artefakt-versionen; `python3 build.py` skapar `index.html`

Innehållet bygger på lärarens genomgång och frågor inför provet samt läroboken s. 116–143.
